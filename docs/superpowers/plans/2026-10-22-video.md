# W-E Video (LiveKit) — Implementation Plan

**Goal:** Replace the synthetic video-consultation surface with real LiveKit
rooms: a persisted session record, a server-minted room token, and a Flutter
call UI that publishes camera/mic.

**Architecture:** Migration `26_video_sessions.sql` + one active-member read
policy + five audited RPCs + Edge Function `video-token` (HS256 JWT minted with
the LiveKit API secret) + `livekit_client` in the app. Provider secrets never
reach the client.

**Spec:** `docs/superpowers/specs/2026-10-22-five-features-design.md` §6.

## Global Constraints

Same as W-A..W-D. Org roles `client | attorney | partner | compliance_officer`.
Session creation: **partner or attorney** (attorney only on a matter they can
read). Joining: any active member of the session's org. Ending: creator or
partner. No recording/transcription in v1. No live deploy/apply.

### Token contract

`POST /functions/v1/video-token` with the user's bearer token:

```json
{ "session_id": "uuid" }
```

Success `200`: `{ "url": "wss://...", "token": "<jwt>", "room": "room_..." }`
Failure: non-2xx `{ "error": "<code>" }`:
`unauthorized | forbidden | session_not_found | session_ended |
provider_not_configured | internal_error`.

The JWT payload: `iss` = API key, `sub` = user id, `exp` = now + 2h,
`nbf` = now - 10s, `video: { roomJoin: true, room: <room_name>, canPublish:
true, canSubscribe: true }`, HS256 with the API secret.

### Task 1: Migration + down

`supabase/migrations/26_video_sessions.sql`:

```sql
begin;

create table public.video_sessions (
  id              uuid primary key default gen_random_uuid(),
  organization_id uuid not null references public.organizations (id) on delete cascade,
  matter_id       uuid references public.matters (id) on delete set null,
  booking_id      uuid references public.consultations (id) on delete set null,
  room_name       text not null unique check (room_name ~ '^room_[a-z0-9]{16,40}$'),
  provider        text not null default 'livekit' check (provider = 'livekit'),
  status          text not null default 'scheduled'
                    check (status in ('scheduled','live','ended','cancelled')),
  scheduled_at    timestamptz,
  started_at      timestamptz,
  ended_at        timestamptz,
  created_by      uuid references auth.users (id) on delete set null,
  created_at      timestamptz not null default now(),
  updated_at      timestamptz not null default now()
);

create index video_sessions_org_created
  on public.video_sessions (organization_id, created_at desc);
create index video_sessions_matter
  on public.video_sessions (matter_id) where matter_id is not null;

alter table public.video_sessions enable row level security;
revoke all on public.video_sessions from anon, authenticated;
grant select on public.video_sessions to authenticated;

commit;
```

Down: drop the five functions, then the table.

### Task 3: RPCs

Files: `create_video_session.sql`, `list_video_sessions.sql`,
`get_video_session.sql`, `mark_video_session_live.sql`,
`end_video_session.sql`; append drops.

**Signatures (no defaults):**
- `create_video_session(uuid, uuid, uuid, timestamptz) returns uuid`
- `list_video_sessions(uuid) returns setof public.video_sessions`
- `get_video_session(uuid) returns public.video_sessions`
- `mark_video_session_live(uuid) returns void`
- `end_video_session(uuid) returns void`

**Gates:**
- create: active member; role partner **or** attorney; a supplied matter must
  belong to the same org and be readable by the caller (attorney/client/
  creator/partner); a supplied booking must belong to the same org. Generate
  `room_name = 'room_' || replace(gen_random_uuid()::text, '-', '')`; status
  `scheduled`; audit `video_session:create`.
- list/get: active member of the session's org.
- mark live: active member of the org; status `scheduled` → `live`,
  `started_at = now()`; audit `video_session:live`.
- end: status `scheduled|live`; caller is `created_by` or a partner; status
  `ended`, `ended_at = now()`; audit `video_session:end`.
- Validation errors: `'permission denied'`, `'video session not found'`,
  `'video session is not scheduled'`, `'video session has already ended'`.

### Task 5: Edge Function `video-token`

`supabase/functions/video-token/index.ts` plus the three secret names in
`supabase/functions/.env.example` (names only) and a `config.toml` entry
(`verify_jwt = true`).

Flow: CORS → caller JWT (`auth.getUser()`, 401) → read the session under the
user client (RLS; missing → 404 `session_not_found`) → reject
ended/cancelled (409) → require `LIVEKIT_URL`, `LIVEKIT_API_KEY`,
`LIVEKIT_API_SECRET` (409 `provider_not_configured`) → mint the HS256 JWT with
Web Crypto (`crypto.subtle`) and base64url helpers → return
`{url, token, room}`. Never log the secret or the token.

### Task 7: UI + platform permissions

- Video screen: upcoming/live/ended list, create sheet (partner/attorney;
  optional matter), join button, end action for creator/partner, honest
  unavailable state.
- Call screen: `Room.connect(url, token)`; enable camera/mic after connect;
  participant grid using `VideoTrackRenderer`; mute/camera toggles that call
  `setMicrophoneEnabled`/`setCameraEnabled`; leave disconnects and calls
  `markLive`/`end` appropriately; rebuild on `RoomListener` events.
- Android: `CAMERA`, `RECORD_AUDIO`, and the camera/mic features in
  `AndroidManifest.xml`. iOS: `NSCameraUsageDescription`,
  `NSMicrophoneUsageDescription` in `Info.plist`.
- No fake call surface in configured builds.
